# Phase 2, steps 3-5: the Laravel app (skeleton, HubDay, TailDay)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a read-only Laravel + Inertia + Vue app in `web/` that shows a chosen ATL day (an hourly timeline against its weather, data caveats and a filterable flight table) and drills down to one tail's legs with labelled gaps.

**Architecture:**
- Laravel connects to the local `flightops` database as `flightops_app`, with `search_path` set to `app_read`, and runs plain `DB::select` against the views built in steps 1-2.
- The two controllers only filter views by `atl_day`, `tail_number` and `leg_order`, and hand rows to Inertia pages.
- Vue renders them. Formatting and chart geometry live in small pure JS modules, which `node --test` checks.
- There is no auth and no Laravel migrations.

**Tech stack:**
- Laravel 13.43 (`composer create-project laravel/laravel`), PHP 8.4
- `inertiajs/inertia-laravel` 3.7, `@inertiajs/vue3` 3.11, Vue 3.5, `@vitejs/plugin-vue` 6, Vite 8
- Tailwind 4 (already in the skeleton)
- Pest 5.3 with `pestphp/pest-plugin-laravel` 5.0
- Node 26 for `node --test`

All of these were installed and run together in a scratch app on 2026-11-22. There, a page rendered July 19's 899 through Inertia as `flightops_app`, `assertInertia` passed, and the role was refused on writes.

## Global Constraints

- **The app reads, never writes.** It connects as `flightops_app` (SELECT on `app_read` only) with `search_path` `app_read`. No Laravel migrations exist or run, and the app needs no tables of its own in phase 2.
- **Day boundaries and status** (the ATL day, status, adverse weather, stale METAR, break labels and caveat flags) come from the views. PHP filters by `atl_day`, `tail_number` and `leg_order`, and nothing more.
- **Days on offer:** `app_read.day_range`, which is 2024-07-01 to 2024-07-31. Any other date gets a 404 page naming that range.
- **Times:** views return UTC. The Laravel pgsql connection sets `timezone` to `UTC`, because this Mac's Postgres runs in `Asia/Kolkata`, which would otherwise send `+05:30` strings. The hub page shows ATL local time and the tail page shows each station's local time, with UTC on hover in both.
- **No added libraries** beyond the stack above: no chart, date, component or HTTP library, and no TypeScript.
- **Commands:**
  - Run PHP and JS commands from `web/`: `./vendor/bin/pest`, `npm test`, `npm run build`.
  - Pest feature tests run against the real local `flightops` database as `flightops_app`, so it must be loaded and migrated through `013`.
  - Run pipeline commands from `pipelines/` as before.
- **Accessibility:** every filter is reachable by keyboard. A chart interaction always has a form-control equivalent, such as the hour select alongside clicking the timeline.
- **`DECISIONS.md`:** append entries, newest last, in its existing format (**Chose / Gave up / Why / Revisit if**).

`web/app/Support/Days.php`:

```php
<?php

namespace App\Support;

use Illuminate\Support\Facades\DB;
use Inertia\Inertia;
use Symfony\Component\HttpFoundation\Response;

class Days
{
    /** @return array{first_day: string, last_day: string} */
    public static function range(): array
    {
        // day_range scans every flight, so read it once per request
        return once(fn () => (array) DB::selectOne('select first_day, last_day from day_range'));
    }

    /** A 404 page naming the loaded range, or null when the day can be shown. */
    public static function notFound(string $day): ?Response
    {
        [$y, $m, $d] = array_map('intval', explode('-', $day));
        $range = self::range();

        if (checkdate($m, $d, $y) && $day >= $range['first_day'] && $day <= $range['last_day']) {
            return null;
        }

        return self::missing("No data for {$day}.");
    }

    public static function missing(string $message): Response
    {
        return Inertia::render('NotFound', ['message' => $message, 'range' => self::range()])
            ->toResponse(request())
            ->setStatusCode(404);
    }
}
```

`web/app/Http/Controllers/HubDayController.php`:

```php
<?php

namespace App\Http\Controllers;

use App\Support\Days;
use Illuminate\Support\Facades\DB;
use Inertia\Inertia;

class HubDayController
{
    public function __invoke(string $date)
    {
        if ($missing = Days::notFound($date)) {
            return $missing;
        }

        return Inertia::render('HubDay', [
            'day' => $date,
            'range' => Days::range(),
            'hourly' => DB::select(
                'select atl_hour, direction, scheduled, on_time, delayed, diverted, cancelled
                 from hub_day_hourly where atl_day = ? order by atl_hour, direction', [$date]),
            'weather' => DB::select(
                'select atl_hour, observed_at, adverse, raw_text from hub_day_weather where atl_day = ? order by observed_at', [$date]),
            'caveats' => DB::selectOne(
                'select metar_stale, rotation_break, aircraft_unresolved, aircraft_medium_confidence, block_mismatch, no_tail
                 from hub_day_caveats where atl_day = ?', [$date]),
            'flights' => DB::select(
                'select flight_id, atl_hour, direction, status, carrier, flight_number, other_station, landed_station, tail_number,
                        sched_dep_utc, sched_arr_utc, actual_dep_utc, actual_arr_utc, dep_delay_min, arr_delay_min,
                        cancellation_code, delays, metar_staleness_min, metar_adverse, metar_stale, rotation_break,
                        aircraft_unresolved, aircraft_medium_confidence, block_mismatch, no_tail
                 from hub_day_flights where atl_day = ? order by atl_hour, direction, carrier, flight_number', [$date]),
        ]);
    }
}
```

`web/app/Http/Controllers/TailDayController.php`:

```php
<?php

namespace App\Http\Controllers;

use App\Support\Days;
use Illuminate\Support\Facades\DB;
use Inertia\Inertia;

class TailDayController
{
    public function __invoke(string $tail, string $date)
    {
        // Allegiant reports tails without the N (320NV), as FAA's N-NUMBER does; the ontology stores N320NV
        $tail = strtoupper($tail);
        $tail = str_starts_with($tail, 'N') ? $tail : "N{$tail}";

        if ($missing = Days::notFound($date)) {
            return $missing;
        }
        if (! DB::selectOne('select 1 from tail_aircraft where tail_number = ? limit 1', [$tail])) {
            return Days::missing("No aircraft {$tail} touched ATL in the loaded data.");
        }

        return Inertia::render('TailDay', [
            'tail' => $tail,
            'day' => $date,
            'range' => Days::range(),
            'aircraft' => DB::select(
                'select manufacturer, model, method, confidence, unresolved_reason, flights from tail_aircraft
                 where tail_number = ? and first_day <= ? and last_day >= ? order by flights desc', [$tail, $date, $date]),
            'legs' => DB::select(
                'with day as (
                     select min(leg_order) as lo, max(leg_order) as hi from tail_legs where tail_number = ? and leg_day = ?
                 )
                 select t.* from tail_legs t, day
                 where t.tail_number = ? and t.leg_order between day.lo - 1 and day.hi + 1
                 order by t.leg_order', [$tail, $date, $tail]),
        ]);
    }
}
```

```js
    if (!value) return null;
    return new Date(value.replace(' ', 'T').replace(/([+-]\d{2})$/, '$1:00'));
}

export function localTime(value, timeZone) {
    const date = toDate(value);
    return date ? new Intl.DateTimeFormat('en-US', { timeZone, hour: '2-digit', minute: '2-digit', hourCycle: 'h23' }).format(date) : '';
}

    return date ? new Intl.DateTimeFormat('en-US', { timeZone, month: 'short', day: 'numeric' }).format(date) : '';

    const date = toDate(value);
```

`web/resources/js/lib/timeline.js`:

```js
export const STATUSES = ['on_time', 'delayed', 'diverted', 'cancelled'];

const empty = () => Object.fromEntries(STATUSES.map((s) => [s, 0]));

// One entry per ATL local hour, with each direction's counts by status, zero-filled.
export function hourBuckets(hourly) {
    const hours = Array.from({ length: 24 }, (_, hour) => ({ hour, dep: empty(), arr: empty() }));
    for (const row of hourly) {
        for (const s of STATUSES) hours[row.atl_hour][row.direction][s] = Number(row[s]);
    }
    return hours;
}

export function total(counts) {
    return STATUSES.reduce((sum, s) => sum + counts[s], 0);
}

export function maxScheduled(hours) {
    return Math.max(1, ...hours.flatMap((h) => [total(h.dep), total(h.arr)]));
}

// Segments outward from the axis: on time nearest it, cancelled outermost.
export function stack(counts, scale) {
    let offset = 0;
    return STATUSES.filter((s) => counts[s] > 0).map((status) => {
        const segment = { status, offset, length: counts[status] * scale };
        offset += segment.length;
        return segment;
    });
}

export function weatherByHour(weather) {
    const hours = Array.from({ length: 24 }, (_, hour) => ({ hour, adverse: false, reports: [] }));
    for (const m of weather) {
        hours[m.atl_hour].adverse ||= m.adverse;
        hours[m.atl_hour].reports.push(m.raw_text);
    }
    return hours;
}
```

```js
export const CAVEATS = {
    metar_stale: 'No METAR within 90 min',
    rotation_break: 'Rotation break',
    aircraft_unresolved: 'Aircraft not resolved',
    aircraft_medium_confidence: 'Medium-confidence aircraft',
    block_mismatch: 'Elapsed time disagrees with times',
    no_tail: 'No tail reported',
};

const CAUSES = { carrier: 'carrier', weather: 'weather', nas: 'NAS', security: 'security', late_aircraft: 'late aircraft' };

// The times and delay at ATL: departures leave ATL, arrivals land there.
export function atlEvent(f) {
    return f.direction === 'dep'
        ? { sched: f.sched_dep_utc, actual: f.actual_dep_utc, delay: f.dep_delay_min }
        : { sched: f.sched_arr_utc, actual: f.actual_arr_utc, delay: f.arr_delay_min };
}

export function caveatsOf(f) {
    return Object.keys(CAVEATS).filter((k) => f[k]);
}

export function filterFlights(flights, { direction = '', carrier = '', status = '', hour = null, caveat = '' }) {
    return flights.filter(
        (f) =>
            (!direction || f.direction === direction) &&
            (!carrier || f.carrier === carrier) &&
            (!status || f.status === status) &&
            (hour === null || f.atl_hour === hour) &&
            (!caveat || f[caveat]),
    );
}

// delays arrives as the jsonb text Postgres sends, e.g. '{"carrier": 10}'.
export function delayText(delays) {
    if (!delays) return '';
    return Object.entries(JSON.parse(delays))
        .map(([cause, minutes]) => `${CAUSES[cause] ?? cause} ${minutes}`)
        .join(', ');
}
```

```js
export const REASONS = {
    no_faa_record: 'no FAA registration found for this tail',
    ambiguous_window: 'more than one registration covers the date',
    no_window_multiple_airframes: 'no registration covers the date, and the tail has had several airframes',

export function axis(legs) {
    const times = legs
        .flatMap((l) => [l.sched_dep_utc, l.sched_arr_utc, l.actual_dep_utc, l.actual_arr_utc])
        .filter(Boolean)
        .map((t) => toDate(t).getTime());
    return { start: Math.min(...times), end: Math.max(...times) };
}

// Left edge and width of a bar, in percent of the axis.
export function bar(from, to, { start, end }) {
    if (!from || !to) return null;
    const span = end - start || 1;
    const a = toDate(from).getTime();
    const b = toDate(to).getTime();
    return { left: ((a - start) / span) * 100, width: Math.max(((b - a) / span) * 100, 0.5) };
}

export function gapLabel(leg) {
    if (leg.connects !== false) return null;
    return `Next origin ${leg.origin} ≠ previous arrival ${leg.prev_station}: ${leg.break_label}`;
}

export function hoursMinutes(minutes) {
    if (Math.abs(minutes) < 60) return `${minutes}m`;
    return `${Math.trunc(minutes / 60)}h ${Math.abs(minutes % 60)}m`;
}
```
